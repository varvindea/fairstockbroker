# Fair Stock Broker

A React + TypeScript + Vite website for a financial services brand.

## Required software

Before running the project locally, install:

- Node.js 20 LTS or newer (recommended: 20.x or 22.x)
- npm (comes bundled with Node.js)
- A code editor such as VS Code

You can download Node.js here: https://nodejs.org/

## Run locally

From the project root, run:

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Useful commands

```bash
# Production build
npm run build

# Preview the production build locally
npm run preview

# Lint the project
npm run lint
```

## Notes

- If you are using a different terminal or environment, ensure the project root is the folder containing `package.json`.
- If the default Vite port is in use, Vite will choose another available port and print the new URL in the terminal.

## Project structure

- `src/` — React app source files
- `public/` — static assets
- `vite.config.ts` — Vite configuration
- `package.json` — project scripts and dependencies
