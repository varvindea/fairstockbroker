01 — Key Learning Outcome

Build Data Tables & Scenario Managers in Excel

By the end of this module you will build a complete Bull / Base / Bear scenario model for any Indian listed company, create a two-variable data table in Excel that updates automatically, and present a valuation range instead of a misleading single number.

🎨
Your Core Takeaway — One Model, Three Stories
A DCF model is not a crystal ball. It is a structured way to ask: “Under what assumptions does this stock make sense?” Bull / Base / Bear forces you to articulate three complete, internally consistent narratives — not just one optimistic guess.
Imagine you are planning a road trip from Mumbai to Goa. You pack for three scenarios: Bull = perfect weather, no traffic, arrive in 8 hours. Base = normal conditions, some stops, arrive in 11 hours. Bear = heavy rain, highway closed, detour via Kolhapur, arrive in 16 hours. You do not know which scenario will happen, but you are prepared for all three. You carry enough water, petrol, and snacks for the Bear case. In investing: the Bull case tells you the upside if everything goes right. The Bear case tells you the downside if things go wrong. And the Base case is your best estimate of the most likely outcome. The key discipline: each scenario must have its own complete, internally consistent set of assumptions — not just different revenue growth rates plugged into the same model.
🔴 Bull: High growth + expanding margins ● Base: Historical trends + modest improvement 🔴 Bear: Headwinds + margin pressure + higher WACC 📋 Excel: Scenario Manager + Data Tables

📋 How to Build a Data Table in Excel (5 Steps)

Step 1: Set up your DCF model with WACC in one cell (e.g., B2) and terminal growth rate g in another (e.g., B3). Your intrinsic value output cell references both. Step 2: Create a 5×5 table: type WACC values in a column (rows), g values in a row (columns). Leave the top-left cell blank. Step 3: In the top-left blank cell, type a formula that equals your intrinsic value output. Step 4: Select the entire table including headers. Step 5: Data → What-If Analysis → Data Table → Row Input Cell = B3 (g), Column Input Cell = B2 (WACC). Excel fills all cells automatically.

📈 Excel Scenario Manager — Save All Three Scenarios

Step 1: Build the Base Case model first with all inputs in a clean assumptions section (revenue growth, margin, WACC, g). Step 2: Data → What-If Analysis → Scenario Manager → Add → Name: “Base Case” → select all assumption cells → enter values → OK. Step 3: Repeat for “Bull Case” (higher growth, lower WACC) and “Bear Case” (lower growth, higher WACC). Step 4: Scenario Summary → select your output cells (intrinsic value per share) → Excel generates a comparison table. Switch between scenarios with a single click.

☀️ What Makes a Good Bear Case

A Bear Case is not just a lower growth rate. It must be a coherent story: What specific risk materialises? How does it affect revenue? Margins? Capital allocation? For CDSL: Bear = SEBI mandates a 30% cut in transaction charges (regulatory risk) + market falls reduce settlement volumes by 20% + CDSL needs to increase IT capex to compete. Each of these changes flows through the P&L and Cash Flow consistently. A Bear Case that is just “revenue growth 12% instead of 18%” without explaining the mechanism is a lazy scenario, not an analytical one.

🚨 The Probability-Weighted Scenario Trick

Assign probability weights to each scenario to get a probability-weighted intrinsic value. Example: Bull (20% probability) × ₹2,400 + Base (60%) × ₹1,600 + Bear (20%) × ₹950 = ₹480 + ₹960 + ₹190 = ₹1,630 probability-weighted value. If market price is ₹2,590 and probability-weighted value is ₹1,630, the margin of safety is negative → potential overvaluation. Adjust probabilities based on your conviction level, not randomly. Most analysts weight Base at 50–60% and split remaining equally between Bull and Bear.

🔍
The Scenario Analysis Investment Decision Rule
Buy Only When the Bear Case Value Provides an Acceptable Return. The Bull Case Is the Bonus, Not the Reason to Buy.
Professional value investors buy a stock when the Bear Case value still provides a reasonable return above WACC. If the Bear Case intrinsic value (₹950 for CDSL) is significantly above the market price — the investment has a “margin of safety” even in bad times. Buying a stock only if the Bull Case works out is speculation, not investing. The discipline: stress-test the Bear Case assumptions hard. Make them genuinely bad, not mildly pessimistic. If the stock still looks interesting at Bear Case value, it is a high-conviction buy. If it only works in Bull and Base — it is a speculation with high conviction, not an investment.

The Golden Rule of Scenario Analysis
Buy When the Bear Case Still Provides a Margin of Safety. Never Buy Based on the Bull Case Alone. Report a Probability-Weighted Range, Not a Single Number.
The Bear Case is the most important scenario to build well because it tells you the maximum you can lose. If the Bear Case value (built on genuinely adverse but realistic assumptions) is still above the current market price — you have found a high-quality investment with downside protection. Every professional value investor — from Warren Buffett to Howard Marks — focuses primarily on downside protection. The upside takes care of itself when quality businesses are bought at prices below even their worst-case value.
05 — Tricks for Better Scenario Analysis

5 Shortcuts to Build Scenarios Faster & Better

These field-tested tricks build better, more credible scenarios — and the Excel tools to automate them — in under 30 minutes per company.

1
Excel Data Table — Automate the Sensitivity
The “2-Variable Data Table” Trick
Instead of manually changing WACC and g one at a time, use Excel’s built-in Data Table to generate all 25 combinations instantly. 5 WACC values × 5 g values = 25 cells, populated automatically. Once set up, the table updates every time you change any assumption in the model. This is the fastest way to build a professional sensitivity table. The colour formatting (conditional formatting in Excel) automatically highlights buy/hold/sell zones.
→ Type WACC values in a column (e.g., A2:A6 = 9%,10%,11%,12%,13%)
→ Type g values in a row (e.g., B1:F1 = 3%,4%,5%,6%,7%)
→ Cell A1 = formula referencing intrinsic value output → Data → What-If → Data Table
✔ 5 minutes to build the full 25-cell table ⚠ Add conditional formatting for colour coding ✗ Never manually change cells — use Data Table
2
Screener.in + History — Anchor Bear Case
The “Historical Worst Year” Bear Case Trick
The most credible Bear Case is anchored in the company’s actual historical worst period. Screener.in’s P&L tab shows 10 years of data. Find the worst year for revenue growth and EBITDA margin in the past decade — that is your Bear Case assumption. The worst year is the most realistic stress test because it already happened. For CDSL: worst year was FY19 (market slowdown reduced trading volumes). Bear revenue growth = FY19 rate. Bear EBITDA = FY19 margin. This anchors the Bear Case in reality, not arbitrary pessimism.
→ Screener.in P&L tab → find the worst revenue growth year in 10 years
→ Find the lowest EBITDA margin year in 10 years
→ Use these as Bear Case inputs → historically validated, not arbitrary
✔ Historical worst = most credible Bear benchmark ⚠ If business has changed structurally: adjust upward slightly ✗ Never invent a Bear worse than historical without a specific new risk
3
Excel Scenario Manager — One-Click Switching
The “Named Scenario Manager” Trick
Excel’s Scenario Manager lets you save multiple sets of assumptions and switch between them instantly. Data → What-If Analysis → Scenario Manager → Add. Name three scenarios: “Bull Case”, “Base Case”, “Bear Case”. For each, select all assumption cells (revenue growth %, margin %, WACC, g) and enter the values. To generate a comparison table: Scenario Manager → Summary → select output cells. Excel produces a formatted comparison sheet automatically. This is faster and more reliable than manually copying values between runs.
→ Build Base Case model with all inputs in one assumptions block
→ Data → What-If → Scenario Manager → Add → name “Base” → select assumption cells
→ Repeat for “Bull” and “Bear” → Summary → select intrinsic value cell
✔ One click to switch between all three scenarios ⚠ Summary report auto-generated by Excel ✗ Never manually overwrite assumption cells — you’ll lose the scenario
4
Probability Weighting — One Actionable Number
The “Probability-Weighted Value” Trick
After building three scenario values, assign probability weights to get a single probability-weighted intrinsic value. Standard weights for Indian equities: Bull 20%, Base 60%, Bear 20%. Adjust based on conviction: if you believe the macro environment strongly favours the Bull, shift to Bull 35%, Base 50%, Bear 15%. The probability-weighted value is more robust than any single scenario because it accounts for genuine uncertainty. When the market price is below the probability-weighted value — there is a margin of safety.
→ Starting weights: Bull 20%, Base 60%, Bear 20%
→ PW Value = (Bull × 20%) + (Base × 60%) + (Bear × 20%)
→ If market price < PW Value → potential buy; > PW Value → wait for correction
✔ PW Value below market price = margin of safety ⚠ PW Value near market = fairly valued, watch for entry ✗ PW Value well above market = caution

The One-Line Scenario Rule
If You Can’t Name the Specific Event That Triggers Each Scenario, You Don’t Have Three Scenarios — You Have One Scenario with Minor Number Variations.
The Bull Case must answer: “What specific event or trend drives this outcome?” (e.g., “India reaches 20 crore demat accounts by FY28”). The Bear Case must answer: “What specific risk materialises?” (e.g., “SEBI mandates a 30% reduction in settlement charges in FY26”). A scenario that cannot be named is not a scenario — it is a sensitivity test. Real scenario analysis requires telling three complete, different stories about the future. The Excel mechanics (Data Table, Scenario Manager) are just tools. The quality of the analysis depends entirely on the quality of the story behind each scenario.
06 — Reference Glossary

Scenario Analysis — Key Terms Explained Simply

Every term used in this module — defined in plain English. Refer back whenever you need a quick refresh while building your own Bull / Base / Bear model.

Term
What It Means in Simple Words
Key Point
Scenario Analysis A structured technique that builds multiple complete versions of the future — each with its own consistent set of assumptions — and attaches a probability to each. Unlike sensitivity analysis (which changes one variable at a time), scenario analysis changes all related variables simultaneously to reflect a coherent economic environment. The output is a valuation range, not a single number. Every professional DCF model includes at minimum three scenarios: Bull, Base, and Bear. Three stories
Bull Case The best realistic outcome — what happens if positive catalysts materialise and the business executes exceptionally. Bull does not mean fantasy; it means the upper end of a plausible range. Bull inputs: highest realistic revenue growth (best year in 10-year history), expanding margins (operating leverage), lower WACC (lower risk premium), and higher terminal growth rate (g = 6%). Probability assigned: typically 15–25%. A Bull case with >30% probability means your Base case is too pessimistic. 15–25% prob.
Base Case The most likely outcome — what happens if historical trends continue without major positive or negative surprises. Base inputs: 5-year average revenue CAGR, average EBITDA margin, standard WACC (India CAPM from Module 11), and g = 5% (India long-run inflation). The Base Case is where the analyst’s highest conviction lies. Probability: 50–60%. The intrinsic value from the Base Case is the primary reference point, but must always be presented alongside Bull and Bear. 50–60% prob.
Bear Case The realistic downside — what happens if a specific named risk materialises and the business faces headwinds. Bear does not mean bankruptcy; it means the lower end of a plausible range. Bear inputs: worst year revenue growth in 10-year history, lowest EBITDA margin year, WACC + 1%, g = 4%. The Bear case is the most important to build correctly because it tells you the maximum plausible loss. If the Bear case value is still above the market price, the investment has genuine downside protection. Probability: 20–30%. 20–30% prob.
Sensitivity Analysis A technique that changes one or two variables at a time while holding everything else constant, to show how sensitive the output is to each input. In DCF, the most common sensitivity is a WACC vs g table (5 WACC values × 5 g values = 25 output cells). Unlike scenario analysis, sensitivity does not tell a coherent economic story — it just shows the mathematical impact of assumption changes. Both are needed: sensitivity shows the range, scenario analysis explains what drives each point in the range. One variable
Data Table (Excel) An Excel feature (Data → What-If Analysis → Data Table) that automatically computes a model output for multiple combinations of two input variables. Set WACC values in a column, g values in a row, and the top-left cell references the intrinsic value output. Excel instantly fills all 25 cells.
Data → What-If Analysis → Data Table → Row input = g cell, Column input = WACC cell
The Data Table is the fastest way to build a professional sensitivity table. It updates automatically whenever any model assumption changes.		 Excel automation
Scenario Manager (Excel) An Excel feature (Data → What-If Analysis → Scenario Manager) that saves multiple named sets of assumptions and allows one-click switching between them. Each scenario stores the values for all selected assumption cells (revenue growth, margin, WACC, g). The “Scenario Summary” feature generates a formatted comparison table showing how all output cells change across scenarios. This eliminates the risk of accidental overwriting of assumptions when running different scenarios manually. One-click switch
Probability-Weighted Value A single intrinsic value that accounts for the probability of each scenario occurring.
PW Value = (Bull × P_bull) + (Base × P_base) + (Bear × P_bear)
Standard weights: Bull 20%, Base 60%, Bear 20%. Example: Bull ₹2,400 × 20% + Base ₹1,600 × 60% + Bear ₹900 × 20% = ₹480 + ₹960 + ₹180 = ₹1,620 probability-weighted value. If market price < ₹1,620 → potential margin of safety. More honest than reporting only the Base Case as “the” intrinsic value.		 Weighted average
Margin of Safety The percentage gap between intrinsic value and market price, providing a cushion against valuation errors and assumption uncertainty.
MoS = (Intrinsic Value − Market Price) ÷ Intrinsic Value × 100
A 30–40% margin of safety means even if your Base Case is 30% wrong, the investment still breaks even. In scenario analysis: buy only when the Bear Case value itself provides a margin of safety at the current price. If Bear Case value > market price, even the worst realistic outcome leaves the investor whole.		 Buy below IV
Internal Consistency The requirement that all assumptions within one scenario must reflect the same economic environment. A Bear scenario cannot simultaneously have low revenue growth (recessionary signal) and low credit costs (boom signal). If the scenario story is “India enters a mild recession,” then revenue growth, margins, NPA rates, WACC, and terminal growth must ALL move in directions consistent with a recession. Internally inconsistent scenarios produce meaningless DCF outputs because they reflect no single real-world event. One macro story
WACC (in scenarios) WACC changes across scenarios because perceived risk changes with the macro environment. Bull: WACC = Base − 1% (optimistic conditions = lower risk premium). Base: standard India CAPM (Module 11 formula). Bear: WACC = Base + 1% (stress conditions = higher risk premium, potentially higher debt costs). Changing WACC by just 1% in each direction is typically sufficient — larger changes (±2-3%) should only be used if capital structure or sector risk materially changes between scenarios. ±1% per scenario
Terminal Growth Rate (g) in scenarios The perpetual growth rate assumption varies between scenarios to reflect different long-run economic outcomes. Bull g = 6%: company grows slightly above India’s long-run inflation, justified by strong competitive position. Base g = 5%: grows at India’s long-run CPI inflation (most conservative defensible assumption). Bear g = 4%: structural headwinds reduce long-run growth below inflation. Never use g above 7% for any Indian company in any scenario — it implies growing faster than the economy forever. 4% / 5% / 6%
OPM% (on Screener.in) Operating Profit Margin percentage — the row on Screener.in’s P&L tab that shows EBITDA as a percentage of Revenue for each year. This is the single most important row for scenario analysis because it directly drives projected EBITDA and FCF. To find scenario inputs: P&L tab → OPM% row → highest value = Bull margin assumption, 5-year average = Base, lowest value = Bear. This takes 30 seconds and provides historically anchored margin assumptions for all three scenarios simultaneously. Screener.in P&L
Two-Variable Sensitivity A sensitivity table that varies two inputs simultaneously and shows the combined impact on the output. The standard DCF sensitivity table varies WACC (on one axis) and g (on the other), showing intrinsic value per share in each of the 25 cells. This reveals which combinations of inputs produce a buy signal (intrinsic value > market price) vs fair value vs sell. Colour-coded: green cells = buy zone, yellow = fairly valued, red = overvalued. More than 50% of the table showing green = high conviction buy signal. WACC × g table
